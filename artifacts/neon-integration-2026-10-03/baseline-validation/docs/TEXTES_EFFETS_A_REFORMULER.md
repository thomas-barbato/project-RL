# Textes des effets — version simplifiée

25 septembre 2026 — reformulations de l'auteur intégrées. Des phrases courtes,
naturelles, centrées sur ce que fait l'effet. Les règles techniques restent dans
la documentation de conception ; les limites importantes sont indiquées
séparément dans la fiche. Pas de paragraphe de fonctionnement dans la description.

## Textes affichés

| Effet | Description |
| --- | --- |
| Décharge circulaire | Crée une zone électrique autour du lanceur. |
| Conduction | Décharge électrique, plus efficace dans l'eau. |
| Brandon | Une touche applique une brûlure temporaire à la cible. |
| Suintement caustique | Laisse temporairement une flaque d'acide sur la case d'impact. |
| Percussion | Repousse la cible de l'attaque. |
| Vol de vie | Vole 50 % des dégâts infligés par l'attaque pour vous soigner. |
| Égide d'impact | Inflige des dégâts et génère un bouclier qui absorbe jusqu'à 3 dégâts du prochain coup reçu. |
| Perforation | Attaque qui transperce la cible jusqu'à 3 cases derrière elle. |
| Marquage | Attaque qui inflige des dégâts et ajoute une marque sur la cible. À 3 marques, elle provoque une explosion cinétique autour de la cible. |
| Ricochet | Le projectile rebondit vers une autre cible proche après l'impact. |
| Catalyse | Cône de flammes qui brûle les cibles sur son passage et provoque une explosion sur les cibles déjà enflammées. |
| Écho différé — maintien à décider | Frappe à nouveau la case touchée après 2 tours. |

Les noms Perforation et Marquage remplacent Perforation rémanente et Fracture
accumulée. Ricochet remplace Alternance dans les essais jouables.
Le cône de Catalyse part expressément du personnage vers la cible.
L'utilité de l'Écho différé a été contestée ; sa suppression n'est pas encore
confirmée. Son texte est simplifié, sans nouvelle mécanique.

## Précisions séparées de la description

- Vol de vie : « Soin : 3 PV maximum par attaque ».
- Égide : « Durée : 2 tours · un seul coup absorbé ».

Ces limites correspondent au prototype actuel. Égide disparaît après le premier
impact absorbé, ou après les deux fins de tour suivantes. Elle n'absorbe pas
trois dégâts à chaque coup pendant toute cette durée. Le texte ne promet pas
cet effet inexistant.

## Témoins supplémentaires du laboratoire

- Témoin : « Aucun effet spécial. Profil de base inchangé. »
- Onde d'impact : « Zone électrique autour de la cible touchée, en mêlée comme à distance. »

Les valeurs du laboratoire restent provisoires ; cette information n'est plus
répétée à la fin de chaque description. Les variantes avec bonus portent
1 à 3 bonus aléatoires de caractéristiques, maniement ou jauges, sans modifier
les dégâts de base. Aucun allègement n'est tiré. Les effets spéciaux restent
propres à l'arme utilisée ; les bonus chiffrés viennent de tous les objets équipés.
