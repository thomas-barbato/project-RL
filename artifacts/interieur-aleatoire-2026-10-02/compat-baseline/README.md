# Copie de comparaison

Cette copie a servi à comparer les échecs avec les sources d’avant le placement mobile de l’intérieur. Elle n’est pas le jeu à lancer.

Les dossiers assets, content, mods et vendor sont des jonctions vers les ressources du projet principal. Ils ont été conservés après le refus automatique de leur retrait. Ne pas modifier ces ressources depuis cette copie.

Les sources de départ proviennent de `../avant`; le moteur et les données restent ceux du workspace. Les adaptations du manifeste et des diagnostics permettent de compiler cette copie sous le nom `compat-baseline`, sans remplacer le binaire du jeu.
