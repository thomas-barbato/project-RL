# Première ville · mobilier r01

La vue « Logement · intérieur » était restée ouverte sur la version r03.
Le comparatif reprend cette vue et réutilise le [lit raccourci r04](LIT-r04.md)
prévalidé. La variante rapproche le pied de lit de 18 px et reprend les pixels
de raccord déjà revus autour de l’ancienne empreinte.

Les cinq occurrences du décor antiémeute `DECO-U01-011` regroupent un
bouclier, un casque et une matraque. La composition du fond accepté a été
rejouée et vérifiée pixel par pixel. Seuls les pixels sous l’empreinte des
objets ont été repris de cette composition, avec les autres décors dans
leur ordre d’origine. Chaque retrait dispose de sa propre couche.

L’aperçu à 64 px par case présente le logement et les cinq emplacements.
Le retrait est proposé pour revue. Les couches et leurs empreintes figurent
dans le [manifeste](../../../assets/source-art/city-cyberpunk12/mobilier-r01/manifest.json).
