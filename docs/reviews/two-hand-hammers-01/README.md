# Marteaux à deux mains — HAM-2H01

Trois nouveaux dessins validés, numérotés 01 à 03, avec manche horizontal.
La réduction conserve le marteau entier, sur fond transparent, sans étirement.
Les sources et prompts exacts sont dans `candidates.json`.

Les deux marteaux actuels restent à une main. Aucun identifiant d’objet,
nom destiné au joueur, dégât, poids ou règle de prise n’a été ajouté.
Le joueur valide ces trois dessins le 22 octobre 2026 par « je valide tout,
sauf les pistolets ». `acceptance.json` fige les sources et les pixels acceptés.
Cette validation porte sur les dessins. Aucun nouveau lot de chiffres ou de
textes d’objets n’a encore été présenté ; le contenu jouable reste distinct.
