# TECHNOMANCIEN-ROBE-RG01 — essais interrompus

22 octobre 2026. Le joueur demande une robe rouge avec bordures dorées et
précise que seules les surfaces rouges changeront lors des variantes futures.
Les cinq retouches ont été lancées avec l’outil intégré `image_gen` ; les
sources et prompts sont conservés sans remplacer la gamme précédente.

Avant leur mise en revue finale, le joueur demande une version sans robe,
jugeant la référence visuelle trop reconnaissable, puis demande de poursuivre
sans robe. Ces retouches sont donc archivées comme essais interrompus.
Aucune acceptation, association aux objets, variante de production ou
intégration ne doit être déduite de leur fabrication.

La revue courante est `../technomancien-no-robe-01/REVIEW.md`.
