# SKILLS-IC30 — deux révisions de Froid

Le retour du joueur sur IC29 demande une tempête de neige pour Blizzard
et propose un crâne gelé pour Explosion cristalline. La nouvelle planche
présente 57 — FR05-C02 et 58 — FR06-C02. Leurs numéros sont conservés.

54 — FR01-C01, 55 — FR02-C01 et 56 — FR04-C01 sont copiés exactement depuis
IC29. Leurs trois masters et quinze exports sont identiques. Ces trois dessins
restent en attente de validation, tout comme les deux révisions ; aucun accord
n'est déduit du retour ciblé. Mur de glace conserve FR03-C03, déjà validé.

Le mode intégré `image_gen.imagegen` crée les deux révisions. `sources.json`,
`generation-plan.json`, `prompts.txt` et `prompts/` conservent les références
et les prompts. Les masters et exports 192, 128, 64, 32 et 24 px sont présents
dans ce dossier. `index.html` présente les tailles natives et un prototype
de disposition dans l'arbre. `native-review-board.png` montre les cinq dessins.

`validation.json` et `protected-before.json` confirment que les 602 fichiers
protégés, dont les ressources actives et les images de IC29, restent inchangés.
Les 336 exports acceptés sont également vérifiés. Les identités, noms, textes
et mécaniques sont conservés. Aucun dessin proposé n'est intégré au jeu.
Une compilation du jeu n'est pas nécessaire pour cette revue d'images.

Le navigateur charge les 23 images à leurs dimensions natives, sans débordement
dans le viewport courant de 1108 × 884 px. Preuves : `browser-validation.json`
et `browser-proof.png`. Les cinq cartes et leurs identifiants sont visibles.
