# ARMOR-FLAT02 — silhouettes réellement distinctes

Huit nouveaux dessins de revue : cinq tenues de départ légères (`AR-N07` à
`AR-N11`) et trois propositions de progression (`AR-N12` à `AR-N14`).
Le **Manteau de mutation `AR-N06`** apprécié par le joueur est repris intact
dans ses trois palettes et seize configurations.

Les libellés des nouveaux dessins ne sont pas des noms d'objets validés.
Leur rendu reste à examiner avant intégration dans le jeu. Les familles de
progression n'ont pas encore de valeurs de défense ou de prérequis chiffrés.

Les formes de tête, coupes, matériaux et volumes changent ; l'anatomie, les
positions articulaires et les placements d'armes restent ceux de `BD-FLAT01`,
révision 2. Le torse sélectionne la tenue complète. Trois palettes par tenue ;
aucune variante supplémentaire pour les illustrations d'inventaire séparées.

La galerie montre les illustrations agrandies, les compositions natives pour
case de 32 px et leur agrandissement exact ×2 pour une case affichée en 64 px.
Le canevas double conserve le débordement autorisé des armes. Les seize
configurations, les trois palettes et les trois fonds peuvent être comparés.

Les huit sources nouvelles sont produites par l'outil **imagegen intégré**.
Les prompts exacts sont dans `generation-specs.json`, les sources et leur
provenance dans `sources/` et `generation-outputs.json`. La composition
reprend le pipeline précédent sans transformation d'arme par tenue.

La revue précédente reste conservée. Les retraits demandés `AR-02`, `AR-04`
et `AR-13`, ainsi que les révisions spécifiques `AR-08`, `AR-10`, `AR-11` et
`AR-12`, sont enregistrés dans le catalogue. Ces anciennes tenues ne sont pas
présentées comme approuvées. Ce lot traite la diversité des nouvelles silhouettes.
Il ne modifie ni les contenus actifs, ni les statistiques, ni les sauvegardes.
