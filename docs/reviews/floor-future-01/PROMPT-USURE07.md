Premier prompt exact :

Use case: stylized-concept. Asset: TRANSPARENT surface-wear decal overlay for an existing top-down industrial steel grating floor in a stylized native64 2D game. Create only the wear layer, not the floor itself. Wide landscape canvas, approximately 2:1. Genuine transparent background with generous empty space between many varied irregular patches of muted brown-gray oxidation, subdued rust, dull desaturated blue-gray residue, small rubbed bare-steel scuffs, scattered tiny chipped-paint marks. Around 30 percent of the canvas has visible wear; the rest is fully transparent. Distribute varied broad and small patches asymmetrically across the full canvas, with calm gaps; avoid identical spots and evenly spaced motifs. Local streaks can be horizontal or vertical but must feel incidental, with broken edges and uneven fading, no large flat rectangle. Restrained rusty umber and dark brown, gray tarnish and a few short quiet pale steel rubs; never bright orange, never luminous. Hand-painted, matte, readable game finish, grouped shapes and restrained sparse small scratches, not photorealistic speckle or noise. Flat orthographic material overlay with parallel axes. Absolutely no underlying grating, no mesh, no floor panels, no tiles, no frame, no border, no surrounding room, no objects, no debris piles, no stones, no puddles, no symbols, no letters, no text, no glowing lights, no baked illumination, no cast shadows, no perspective, no isometric diamond. The existing floor will be kept intact beneath this transparent wear decal. The overlay will be masked onto existing metal bars so its holes and silhouette stay unchanged. Show no checkerboard pattern; that must be transparency.

Prompt final d'édition des teintes :

Use case: precise-object-edit. Edit this existing transparent wear decal overlay. Keep its wide landscape canvas, genuine transparency, sparse asymmetric distribution and approximate patch silhouettes. Change only the worn surface colors and internal texture so the wear remains visibly legible after reduction to native64 game scale: oxidation in distinctly darker rusty red-brown and umber, with some charcoal greasy tarnish; exposed rubbed steel noticeably paler cool gray with a few short off-white edge scuffs. The previous brown-gray midtones were too similar to a blue-gray grating, so increase material separation and contrast, not the number of marks. Give the larger patches solid opaque cores with broken fading edges. Keep most of the canvas fully transparent. Matte hand-painted game material, restrained practical industrial wear, grouped readable shapes and no photographic micrograin. Do not add any grating, mesh, panel, floor, objects, debris, stones, symbols, text, frame, glow, lights, cast shadows or perspective. Preserve existing transparency; show no checkerboard. This is only a transparent decal layer to be masked onto existing steel bars.
