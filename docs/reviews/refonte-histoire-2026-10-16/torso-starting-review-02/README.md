# TORSO-STARTING-02 — cinq tenues de départ intégrées

Le 20 octobre 2026, le joueur accepte « Valider les cinq et leurs couleurs ».
Ce complément corrige l’omission de cinq objets équipables dans le premier
inventaire. Il est distinct de l’accord sur les quatorze autres modèles.

- TOR-200 : Tenue d’assaut, FIN-01.
- TOR-201 : Tenue technique, FIN-14.
- TOR-202 : Tenue de traque, FIN-15.
- TOR-203 : Tenue rituelle, FIN-16.
- TOR-204 : Tenue métamorphe, FIN-17.

Les cinq dessins et leurs **24 associations icône / couleur / tenue** sont
actifs. A conserve l’original ; B est bleu ardoise, C vert mousse, D rouille
et E rouge sombre. La Tenue rituelle est déjà rouge en A et n’a pas de E.
Les masques base/core acceptés de FIN-01 incluent le tissu du torse, avec
la tête et les bras nus protégés. Les anciennes couleurs et les portraits
ne changent pas. Les identifiants, bonus et règles des objets restent identiques.

Les [sources et prompts imagegen intégrés](../../../../assets/source-art/torso-starting-review-02/prompts.json)
et les fichiers acceptés sont conservés avec leurs empreintes dans
[candidates.json](candidates.json). La planche originale se trouve dans
`proofs/depart-native.png`. Les contrôles communs aux 19 modèles sont
consignés dans [integration-checks.json](../torso-icons-review-01/integration-checks.json).

La [galerie](../../../../artifacts/torso-icons-review-01/depart.html) conserve
la preuve de validation et renvoie aux nouvelles captures réelles de jeu.
Le [bilan commun](../torso-icons-review-01/README.md) décrit les ressources,
les palettes, la sauvegarde et les contrôles d’intégration.
