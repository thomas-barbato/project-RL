# Archive du camp et des premières bulles

Ces fichiers conservent les sources de fabrication et l’historique des essais
du camp r03 à r09b, des trois premières bulles et de leurs lanceurs. Ils ne
sont plus des outils actifs ni des exemples compilés par Cargo.

- `tools/` : anciens générateurs et publications de galerie.
- `examples/` : anciens prototypes Rust et leurs modules.
- `launchers/` : lanceurs remplacés par `cargo run` et `Jouer.cmd`.
- `snapshots/` : adaptateurs Rust avant simplification, dont les variantes r01.

Les anciens fichiers `assets/prototypes/handcrafted-camp-01/` sont conservés
à l’identique sous `assets/source-art/refonte-histoire-2026-10-16/handcrafted-places-review-01/prototype-history/`.
Les ressources du jeu sont dans `assets/maps/cryogenic-camp-01/`.

Les scripts sont conservés exactement avec leurs anciens chemins et leurs
anciens calculs de racine. Pour rejouer une étape, restaurer leurs chemins dans
un dossier de travail séparé et rétablir les entrées depuis le registre ; ne
pas les exécuter directement depuis cette archive dans le projet courant.
Les correspondances et empreintes sont dans
`docs/maintenance/nettoyage-2026-10-18/camp-dialogues/cleanup-plan.json`.

Aucune image de cette archive n’acquiert une nouvelle validation. Les décisions
sont dans `docs/reviews/refonte-histoire-2026-10-16/handcrafted-places-review-01/`.
